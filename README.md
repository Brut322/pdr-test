# Тренажер ПДР — підготовка до теоретичного іспиту (Україна)

Безкоштовний тренажер без реклами, реєстрації та бекенду. Статика: відкрив і
працює. Прогрес, помилки й улюблені зберігаються в `localStorage` браузера і
нікуди не відправляються.

## Джерело питань

Офіційні матеріали Головного сервісного центру МВС: «Екзаменаційні питання та
відповіді для складення іспиту з теоретичної підготовки / перепідготовки водіїв
транспортних засобів», затверджені **наказом ГСЦ МВС від 29.10.2025 № 225**.

- [Сторінка ГСЦ МВС з офіційними файлами](https://hsc.gov.ua/index/poslugi/vidacha-posvidchennya-vodiya/pitannya-ta-ispit-z-pdr/)
- PDF з питаннями сформовано 10.11.2025, таблиця відповідей — 11.11.2025
- Датасет для сайту зібрано 16.08.2026
- Разом: 2332 питання, 71 розділ, 1168 зображень

Питання й відповіді витягнуті з PDF автоматично — конвеєр на Python написав
Claude (Anthropic). Таблиця відповідей була сканом без текстового шару, тому її
читав окремий конвеєр із власним класифікатором цифр; результат звірено з
незалежним розпізнаванням, а спірні клітинки — вручну по зображеннях.

> **Це не офіційний ресурс ГСЦ МВС.** Попри перевірки, помилки розпізнавання
> виключити не можна. При розбіжності вірте офіційному файлу.

Знайшли помилку — напишіть: [@vl_taran](https://t.me/vl_taran). Вкажіть номер
розділу й номер питання.

## Режими

| Режим | Що робить |
|---|---|
| Вчити по темах | розділ за розділом, правильна відповідь одразу; можна перемішувати |
| Іспит як в СЦ | 20 питань, 20 хвилин, стоп після 3-ї помилки |
| Мої помилки | питання, на яких помилились; правильна відповідь прибирає зі списку |
| Улюблені | ручна добірка по зірочці (клавіша `F`); правильна відповідь звідси нічого не прибирає |
| Прогрес | % по кожній темі, загальна статистика, перенос улюблених на інший пристрій |

**Категорії** перемикаються в шапці: A1/A, B1/B, C1/C, D1/D, причепи (BE…DE), T.
Розділи 1–39 спільні для всіх, далі йдуть чотири додаткові розділи на групу.
Прогрес прив'язаний до id питання, тому спільна теорія не скидається при
перемиканні категорії.

**Перенос улюблених.** Бекенду немає, тож добірка їде в самому посиланні:
«Прогрес → Перенести на телефон» дає URL виду `…/#/import?f=1-1,19-32`, який на
іншому пристрої доливає ці питання до улюблених.

## Запуск локально

Достатньо відкрити `index.html` — дані лежать у `data/questions.js`, тому навіть
`file://` працює. Через сервер:

```bash
python3 -m http.server 8080   # http://localhost:8080
```

## Структура

```
index.html           розмітка, шапка й вкладки
css/app.css          стилі; акцент --accent, зелений/червоний — лише семантика відповіді
js/app.js            уся логіка: роутер на hash, сховище, режими, рендер
data/questions.js    датасет (той самий JSON, обгорнутий у window.PDR_DATA)
data/questions.json  той самий датасет чистим JSON, якщо комусь потрібні дані
images/              1168 малюнків до питань
```

Формат запису:

```json
{
  "id": "33.4-42", "section": "33.4", "sectionName": "...", "number": 42,
  "text": "...", "options": ["...", "..."],
  "correctIndex": 1,      // 0-based індекс у options
  "correctNumber": 2,     // 1-based, як в офіційній таблиці
  "image": "images/s8-1_q42.jpeg", "images": ["images/s8-1_q42.jpeg"]
}
```
